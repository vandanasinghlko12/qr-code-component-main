# Reflection Question:
### How did using Figma designs as references affect your coding process?
Using Figma designs as references made my coding process easier because I had a clear idea of how the final webpage should look. It helped me understand the layout, spacing, colors, fonts, and alignment.
### What challenges did you encounter when aligning your code with the design specifications
One of the main challenges I faced was getting the spacing, alignment, and sizing of elements to match the Figma design. I was sometimes confused about when to use pixels, percentages, or other CSS units.

### How can the feedback and community resources on Frontend Mentor help you improve as a developer?

By providing the clear README.md or style-guide what place they have use what font, font-family or color.
